# Intro to C++

This is a personal repository that brings together concepts learned in an **Introduction to Programming** course **based on C++**, along with additional **self-taught studies**.

The content follows a logical learning progression:

- Variables  
- Conditions and loops 
- Arrays and matrices  
- Functions  
- Objects  
- Namespaces  
- Pointers  
- Use of standard libraries  

All exercise files were developed and tested using **GDB Online**.

A brief summary of the learning process and access to the `.cpp` files in the [`exercises`](./exercises) directory can be found [here](https://onlinegdb.com/p7ZulwYNU).
